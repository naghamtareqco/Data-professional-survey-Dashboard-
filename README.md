# Data Professional Survey Dashboard

## Overview
This project is an interactive Power BI dashboard that analyzes survey responses from data professionals. The dashboard provides insights into salaries, work-life balance, job satisfaction, programming language preferences, and career challenges. Users can interact with the dashboard by selecting a country, which dynamically filters all visuals to display country-specific insights.

## Objectives
- Analyze salary trends across different data-related roles.
- Compare work-life balance and salary satisfaction.
- Explore the distribution of survey respondents by country.
- Identify the most popular programming languages among data professionals.
- Understand the challenges of breaking into the data field.
- Enable interactive exploration through dynamic filtering.

## Dashboard Features
- Interactive country selection that filters the entire dashboard.
- Survey Respondents KPI.
- Average Age KPI.
- Average Salary by Job Title.
- Work-Life Balance Score.
- Salary Satisfaction Score.
- Country Distribution.
- Favorite Programming Language Analysis.
- Difficulty Breaking into the Data Field.
- Dynamic cross-filtering across all visuals.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Modeling
- Interactive Visualizations

## Key Insights
- Compare salaries across different data careers.
- Analyze survey responses by country.
- Evaluate work-life balance and salary satisfaction.
- Explore programming language preferences.
- Identify how difficult respondents perceive entering the data industry.
